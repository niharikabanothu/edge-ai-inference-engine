# Edge AI Inference Engine

Real-time object classification on Raspberry Pi using TensorFlow Lite.

## Overview
Deployed an optimized ML model on Raspberry Pi for real-time object classification at the edge. Applied model quantization and pruning to reduce inference latency by ~60%.

## Tech Stack
- TensorFlow Lite
- Raspberry Pi
- Python

## Features
- Real-time object classification on edge device
- Model quantization & pruning (~60% latency reduction)
- Sensor input pipeline with hardware-accelerated inference
- Lightweight deployment without cloud dependency
